# Ficha6POO
Considere que se pretende desenvolver um sistema para a gestão de uma empresa
que possui carros para alugar (classe CarRental). Pretende-se ter uma classe
que agrupe a informação sobre os carros, sendo que existem carros de diferentes
características que são oferecidos aos clientes. O sistema a desenvolver deverá ser
capaz de representar essa informação e fornecer um conjunto de funcionalidades
que permita consultá-la e manipulá-la, bem como registar uma viagem num
determinado carro.
